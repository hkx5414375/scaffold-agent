# ADR 0043：Python 文件资产

- 状态：已接受
- 日期：2026-09-01

## 背景

业务系统经常需要上传许可证、附件、商品图片和导入文件。让不同 AI 在每个 FastAPI 项目中临时设计文件表、对象路径、大小限制、租户隔离和数据库与文件系统之间的补偿，会重复消耗 Token，并容易出现目录穿越、覆盖已有文件、跨租户读取或残留孤儿文件。

## 决策

1. Python 适配器支持 `file-assets` `0.1.0`，可单独使用，也可与 `organization-tenancy`、业务 CRUD 和共用管理端组合；PostgreSQL 与 MySQL 使用同一 Blueprint 和 HTTP 契约。
2. `FileAssetService` 是业务调用入口。HTTP 只暴露上传、元数据读取、有界游标列表、附件下载和删除，不暴露内部 `storage_key`，也不允许用用户文件名构造对象路径。
3. 上传以 64 KiB 分块读取，单文件最多 10 MiB，同时计算 SHA-256。默认 `LocalBlobStore` 只接受受限对象键，在目标目录创建临时文件、刷新到磁盘后用硬链接进行不覆盖发布，并拒绝对象目录中的符号链接。
4. 元数据包含组织范围、名称、媒体类型、大小、摘要、内部对象键、生命周期和时间戳。创建和软删除与审计事件在同一数据库事务内完成；元数据创建失败会删除已发布对象，字节删除失败会恢复元数据。
5. 下载统一使用附件响应、编码后的文件名和 `X-Content-Type-Options: nosniff`。跨租户标识、已删除记录和不存在记录统一返回未找到，存储或数据库原始错误不会进入公开响应。
6. `FILE_STORAGE_ROOT` 是必填运行时配置，不能写进 Blueprint 或源码。业务可替换 `BlobStore`，但必须保留大小上限、只创建发布、摘要、租户范围和补偿语义。
7. SQLite 契约测试执行完整 Alembic 迁移；CI 在 PostgreSQL 与 MySQL 真库上验证迁移、审计、租户隔离和软删除，并对共用 Vue 文件管理页执行锁定安装、Lint、测试和生产构建。

## 结果

- Go、Java、Python 使用同一能力名、HTTP 操作和安全边界，AI 只需调用语言原生文件服务。
- 本地对象存储适合单实例和共享持久卷；S3、COS 等远端对象存储适配器留给后续版本，不改变业务服务契约。
- 病毒扫描、图片转换、断点续传、公开分享和生命周期清理不属于 `0.1.0`，后续能力应通过可靠任务组合实现。
