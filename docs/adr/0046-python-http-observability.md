# ADR 0046：Python 安全 HTTP 可观测性

- 状态：已接受
- 日期：2026-09-01

## 背景

生成服务需要最小而可移植的请求关联、访问日志、HTTP 指标和数据库就绪信号。临时生成的中间件容易把查询串、请求体、Header、异常内容或用户输入标签写入日志和指标；SQLAlchemy 的连接池等待还可能使公开就绪接口超过预期时限。

## 决策

1. Python `observability` `0.1.0` 支持 PostgreSQL 与 MySQL，不新增数据库迁移，也不引入遥测 SDK。
2. 纯 ASGI 中间件只接受 8–64 位 ASCII 字母、数字、连字符或下划线组成的 `X-Request-ID`，其他输入替换为随机 UUID。校验后的值写入请求状态并返回响应 Header。
3. 每个请求产生一条紧凑 JSON 访问日志，只包含请求 ID、规范 HTTP 方法、去除控制字符且最多 2,048 字符的 URL Path、状态和耗时。中间件不会读取查询串或请求体，也不会记录 Header、异常类型或异常内容。生成启动命令关闭 Uvicorn 内置访问日志，避免其重新记录查询串。
4. 未处理异常在尚未发送响应时转换为不含内部信息的 JSON 500。已开始流式响应的异常继续向服务器传播，但观测记录固定按 500 计数且不记录异常值。
5. `HttpObserver` 使用进程内锁维护请求总数、处理中数量、500 失败数和总耗时。`GET /metrics` 输出无标签 Prometheus 文本，不包含路由、请求 ID、租户或其他用户派生维度。
6. `DatabaseProbe` 使用单线程有界执行器，把连接获取和 `select 1` 整体限制为 2 秒；超时或任何驱动失败统一返回不可用，并在应用生命周期结束时停止接收新探测。
7. `GET /readyz` 成功只返回 `ready`，失败只返回 `unavailable`；`GET /healthz` 仍只表示进程存活。运维端点不做应用认证，公开部署必须在入口或私网边界保护。
8. SQLite 单元测试验证超时和 HTTP 契约；CI 在 PostgreSQL/MySQL 真库验证实际就绪结果。

## 结果

- Go、Java、Python 具备同名且同安全边界的最小观测能力，AI 不需要重复选择日志字段或指标标签。
- 指标随进程重启清零且不跨副本聚合；采集、持久化和告警由外部 Prometheus 兼容系统负责。
- 路由标签、分布式追踪、厂商 Exporter 和业务指标不属于 `0.1.0`。
