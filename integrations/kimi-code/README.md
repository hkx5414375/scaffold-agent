# Kimi Code

Copy [`mcp.json.example`](mcp.json.example) to one of these locations after replacing the executable path:

- User scope: `~/.kimi-code/mcp.json`
- Project scope: `.kimi-code/mcp.json`

Start a new Kimi Code session after adding the server. Use `/mcp` to inspect connection status. Project-scoped commands require workspace trust.

Reference: [Kimi Code MCP documentation](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/mcp.html).
